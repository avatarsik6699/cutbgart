# Active phase evidence

This directory is reserved for evidence produced by the currently active phase. Phase 33 will add:

- `PHASE_33_BASELINE.md`
- `PHASE_33_RESULTS.md`

Historical Phase-31/32 evidence is under `docs/archive/audits/` and is not current product
acceptance evidence.

Phase-specific active evidence is stored in versioned `PHASE_XX_RESULTS.md` and
`PHASE_XX_REPORTS.json` pairs. Phase 42 additionally owns the frozen complete-product parity
matrix, regression findings, and performance research documents in this directory.
