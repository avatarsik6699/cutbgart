# Active phase evidence

This directory is reserved for evidence produced by the currently active phase. Phase 44 final
evidence is recorded in
[`PHASE_44_T1_FINAL_VERIFICATION.md`](./PHASE_44_T1_FINAL_VERIFICATION.md); the earlier T10 diagnosis and recovery-plan gate is
recorded in [`PHASE_44_T10_MAGIC_DIAGNOSIS.md`](./PHASE_44_T10_MAGIC_DIAGNOSIS.md). The attempted
implementation and its accepted performance stop condition are recorded in
[`PHASE_44_T10A_MAGIC_RECOVERY_RESULTS.md`](./PHASE_44_T10A_MAGIC_RECOVERY_RESULTS.md). The T12
pre-implementation semantics and approval gate are recorded in
[`PHASE_44_T12_MODEL_REPROCESSING_PLAN.md`](./PHASE_44_T12_MODEL_REPROCESSING_PLAN.md). T2
intentionally does not establish a pre-refactor render-counter or Chrome-trace baseline.

Historical Phase-31–43 evidence is indexed under [`docs/archive/audits/`](../archive/audits/).
Archived reports remain reproducible inputs for their retained `profile:phase-* -- --verify`
commands, but they are not current implementation scope or proof of Phase-44 performance.
